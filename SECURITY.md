## Reporting a Vulnerability
We take the security of our infrastructure automation and deployment tools seriously. If you discover a security vulnerability (such as privilege escalation, unintended port exposure, credential leakage, or sandbox bypass), please report it responsibly:

1. **Do NOT open a public GitHub issue.**
2. Submit a report privately via [GitHub Private Vulnerability Reporting](https://github.com/你的GitHub用户名/你的仓库名/security/advisories/new) or email the security maintainer directly at **[你的邮箱]**.
3. Include steps to reproduce, affected configuration files or scripts, and potential impact.

## Response & Disclosure Process
- **Acknowledgment:** Within 48 hours of receiving the report.
- **Triage & Fix:** Security patches are prioritized and validated in isolated environments before release.
- **Coordinated Disclosure:** Once a fix is published, we credit the reporter (if desired) in our release notes and security advisories.
